4.  STEP 4 — CIFAR-FS BERTINETTO SPLIT + EPISODIC META-TRAINING
================================================================================
Phase:    2
RQ:       Foundation for RQ2 and RQ3 on the real benchmark.
STATUS:   NEXT
DEPENDS:  Steps 1, 2, 3 (all done)
ESTIMATE: 1-2 weeks

GOAL:
  Replace the CIFAR-100-test stand-in with the proper Bertinetto 2019
  64/16/20 CIFAR-FS split, replace single-episode training with
  episodic meta-training on the train split (with per-epoch validation
  on the val split and early stop), and produce the Phase A baseline
  numbers reported as mean ± 95% CI on 600 test-split episodes.

PROTOCOL DECISIONS (committed in plan.txt §4 Phase 2):
  A. Meta-training paradigm = ProtoNet-style episodic meta-training.
     Each episode is one OUTER gradient step. The adapter is the
     trainable PEFT module; the classifier head is parameter-free
     prototype similarity computed from the support set inside each
     episode. Per-episode-from-scratch fine-tuning is kept ONLY as a
     test-time-evaluation fallback if the meta-trained version
     collapses.
  B. Train-time shot count = 5-shot only. 1-shot models are trained
     in Step 10 (the MVT grid).
  C. Train-time way count = 5-way. (Matches test-time; the standard
     CIFAR-FS protocol does not vary way between train and test.)

ARCHITECTURE DEVIATION FROM PROPOSAL (documented):
  proposal.txt §5B describes the head as "Linear(features → K) + ReLU
  → evidence". For episodic meta-training across hundreds of unseen
  test classes, a fixed trained linear head with K output slots cannot
  carry class identity between train and test classes. We therefore
  replace the trained linear head with a parameter-free PROTOTYPE
  similarity head:
    prototype_k = mean(adapter_features[support_y == k])
    logit_q_k   = -||adapter_features[q] - prototype_k||^2   (L2)
                  or cosine(adapter_features[q], prototype_k)
  The Dirichlet evidence pipeline is unchanged:
    evidence = softplus(logits)
    alpha    = evidence + 1
    S        = sum(alpha)
    p        = alpha / S
    vacuity  = K / S
  This deviation is documented in Chapter 3 (Methodology) of the
  thesis. The standard CIFAR-FS literature (ProtoNet, R2D2,
  MetaOptNet) all use prototype-style heads; ours is the same with an
  evidential Dirichlet on top.

  4.5  src/models/bpeft_model.py (MODIFIED)

  4.6  src/trainers/episodic_trainer.py (NEW)
       - class EpisodicTrainer with __init__(model, loss_fn,
         optimizer, num_epochs, episodes_per_epoch, val_iterable,
         val_episodes_per_epoch, early_stop_patience, kl_weight_max,
         kl_anneal_steps, logger, wandb_run).
       - .fit(train_iterable):
           for epoch in range(num_epochs):
               for episode_idx, (sx, sy, qx, qy) in
                       enumerate(train_iterable.take(episodes_per_epoch)):
                   optimizer.zero_grad()
                   adapted_support = model.adapter_features(sx)
                   adapted_query   = model.adapter_features(qx)
                   logits = prototype_head(adapted_support, sy,
                                            adapted_query)
                   loss = loss_fn(logits, qy, step=global_step,
                                   num_classes=n_way)
                   loss.backward()
                   optimizer.step()
                   global_step += 1
                   if wandb_run: wandb_run.log(... per-episode metrics)
               # End of epoch.
               val_acc, val_ece, val_brier = self._validate(
                       val_iterable, val_episodes_per_epoch)
               if wandb_run: wandb_run.log(per-epoch metrics, step=epoch)
               # Early-stop on val accuracy plateau.
               if val_acc <= best_val_acc:
                   no_improve_epochs += 1
                   if no_improve_epochs >= early_stop_patience: break
               else:
                   best_val_acc = val_acc
                   no_improve_epochs = 0
                   torch.save(model.state_dict(), best_ckpt_path)
       - KL anneal: linear ramp 0 → kl_weight_max over
         kl_anneal_steps OUTER steps (= 1 per episode). With
         episodes_per_epoch=100 and num_epochs=20, total outer steps
         = 2000; spec'd kl_anneal_steps = 500-1000.

RISKS:

  R-EPISODIC-COLLAPSE
    The episodic trainer can converge to a uniform-output baseline if
    the KL anneal is too aggressive or the LR is too high. Mitigation:
    the smoke assertion in tests/test_episodic_trainer.py catches
    val_acc ≤ 1/n_way; in scripts/train.py, after the first epoch, if
    val_acc < 0.30 abort with a clear error. This stops Colab burning
    GPU on a doomed run.

  R-FALLBACK-PROTOCOL
    If meta-training fails to converge after one full debug cycle (lr,
    kl schedule, episodes_per_epoch), fall back to the per-episode-
    fine-tune protocol on the Bertinetto test split — i.e. Step 1's
    protocol applied to the real classes via evaluate_finetune(). This
    still produces valid Phase 2 numbers and unblocks Phase 3. Document
    the fallback in step4.txt and in Chapter 4 of the thesis.

  R-SPLIT-DRIFT
    The Bertinetto split JSON must NEVER be regenerated. If a future
    contributor regenerates it (e.g. with a different RNG), comparisons
    between phases become invalid. The split file's top-line comment
    must read "DO NOT REGENERATE — frozen Bertinetto 2019 IDs".

ACTIONS:

  5.1  src/adapters/lora.py (REWRITE from current stub)
       - LoRALayer(in_features, out_features, rank, alpha,
                   dropout=0.0).
         W_eff = W_frozen + (alpha / rank) * A @ B
         A: (in_features, rank), B: (rank, out_features).
         A initialised Kaiming uniform; B initialised to zero so the
         layer starts as identity.
       - LoRAAdapter: wraps a frozen nn.Module's nn.Linear / nn.Conv2d
         layers in LoRA. For ResNet-18, the natural targets are the
         1×1 convs in the final block and the conv2 of each
         BasicBlock; cfg.adapter.lora_targets in YAML controls which.
       - Smoke test (already exists): identity at init. Strengthen
         to: trainable_param_count(LoRAAdapter(rank=16)) matches the
         analytical formula 2 * rank * (in + out).

  5.2  src/adapters/bitfit.py (NEW)
       - BitFitAdapter: a wrapper that unfreezes ONLY the bias
         parameters of the backbone (and, optionally, adds a small
         number of new bias parameters to a target set of layers).
       - Counts trainable params: just the sum over named_parameters
         where ".bias" in name and requires_grad is flipped to True.
       - For ResNet-18 with all bias terms unfrozen: ~5K parameters
         (well under the proposal's "<500" target only if restricted
         to a subset of layers; document the choice in the writeup).

  5.3  src/adapters/full_ft.py (NEW, baseline)
       - FullFTAdapter: unfreezes the ENTIRE backbone. No adapter
         module is inserted; .adapter_features(x) is just
         backbone(x).
       - This is the proposal §6 "Full Fine-Tuning" primary baseline.
       - Trainable param count: full backbone (e.g. ResNet-18 ≈
         11.7M params).
       - Expected behaviour: catastrophic overfitting on 5-shot
         (25 support images); accuracy on query collapses below the
         PEFT methods. That outcome IS the result — it shows PEFT is
         necessary in the few-shot regime.

  5.4  src/adapters/linear_probe.py (NEW, baseline)
       - LinearProbeAdapter: backbone stays frozen; no adapter
         inserted; only the prototype / linear head is trainable.
       - The proposal §6 "Linear Probing" primary baseline.
       - Trainable param count: zero adapter params + the head.
         Under the prototype-head protocol (Step 4) the head has
         zero parameters, so this is the most extreme PEFT case:
         all knowledge transfer comes from the frozen ImageNet
         features.

  5.5  src/models/bpeft_model.py (MODIFIED, additive)
       - Factory accepts
            cfg.adapter.type ∈ {bottleneck, lora, bitfit,
                                full_ft, linear_probe}.
       - Each adapter type implements the same interface:
           build_adapter(backbone, cfg) → nn.Module that exposes
             .adapter_features(x): Tensor → adapted feature Tensor
       - For full_ft, the wrapper also flips requires_grad=True on
         the underlying backbone.
       - For linear_probe, the wrapper is the identity but the
         backbone stays frozen — distinction from full_ft is one
         line of code.

  5.6  configs/exp_phase3_lora_<head>.yaml          (2 files)
       configs/exp_phase3_bitfit_<head>.yaml        (2 files)
       configs/exp_phase3_full_ft_<head>.yaml       (2 files, baseline)
       configs/exp_phase3_linear_probe_<head>.yaml  (2 files, baseline)
       = 8 configs.
       - All extend base.yaml + the Phase 2 episodic trainer config.
       - The full_ft configs use a smaller LR (e.g. 1e-5 vs 5e-3)
         and weight_decay=1e-4 to give it a fair chance against

    Phases 2 (Step 4) and 5 (Step 10) are the long-running phases.
    scripts/train.py MUST support --resume-from <checkpoint> before
    Step 10 starts. Save checkpoints to Drive every epoch in episodic
    training, every config in the grid.

    All experiments live in this single repo. No fork, no parallel
    notebook playground. Step writeups (step_writeups/*) are the
    durable record of what was tried, even for failed attempts.

R4  600 TEST SEEDS ARE FROZEN
    configs/test_episodes.yaml is committed truth. Every step's final
    evaluation reads from this file. Do not regenerate, do not slice
    silently. Same for the (new) configs/val_episodes.yaml.

    plan.txt §5 fixes the drop order for Step 12 extensions. Use it.
    The temptation to drop the WRITING phase (Step 13) to fit one more
    experiment is the most common way thesis projects fail. Resist it.

R6  EPISODIC COLLAPSE
    Specific to Step 4. Smoke-test: after epoch 1, val_acc must
    exceed 1/n_way + 0.05. If not, abort and re-tune.
